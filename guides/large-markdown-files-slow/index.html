Keep the useful content manageable

A heavy Markdown file.
A few things to try.

The quick answer

Large embedded images, tables and code blocks can make Markdown heavy. Use Zizeg’s Source view for text edits while Preview loads, and try separate image assets when Base64 pictures make the source unwieldy.

Look beyond the word count.

  • Check the images. Long data:image references store picture data inside the Markdown. Save As… can create an Assets Folder copy without changing the original.
  • Keep editing in Source. Large documents can appear in stages. Preview is read-only until loading finishes, while Source remains available.
  • Consider the structure. Reference definitions or one very long code block can require a full load. For navigation rather than loading, use headings, the outline and Find.
