Choose how the pictures travel

Separate pictures.
Or one Markdown file?

The quick answer

Use separate image assets for readable source and everyday editing. Choose Base64 when a single .md matters and the receiving app supports data-URI images. Zizeg’s Save As… creates a converted copy without changing the original.

Pick the trade-off that fits.

  • Assets keep source light. Pictures stay in a companion folder with short Markdown references. Move that folder with the .md to preserve relative paths.
  • Base64 keeps pictures inside. The file is easier to carry alone, but encoded images make the source larger. Embedding packages data; it does not compress it.
  • Try either on a copy. Choose File → Save As… and select Assets Folder or Base64 Data URI. Check the pictures and test the copy in its destination app.
