Choose the version you mean to keep

Another app changed it.
Which version do you want?

Keep the updated file or the version open in Zizeg, with a clear choice when they differ.

The quick answer

Choose Reload to use the externally changed version on disk. Choose Keep My Version to write the content currently open in Zizeg. If both versions matter, duplicate the file on disk before choosing Keep My Version.

Two versions of the same file.

You have a Markdown file open in Zizeg, and another editor, an AI agent, or a sync service changes it on disk. When Zizeg asks what to do, choose which content you want to keep.

The external-change choices
ChoiceWhat happens
ReloadReplace the open content with the version written to disk.
Keep My VersionWrite the version currently open in Zizeg over the changed disk version.

For example, if an agent has just finished updating a plan and you want to read its result, choose Reload. If your open document is the version you intend to keep, choose Keep My Version.

Keep My Version applies your choice immediately.

Zizeg checks that the external revision has not changed again, immediately writes your open version, verifies the result, and resumes autosave.

If the disk changes again before the decision can be applied, Zizeg asks again. After that, ordinary edits continue to autosave.

A reload is one undo step. If you need to bring back the content you had before it, use Edit → Undo (⌘Z).

You can preserve another version before deciding.

Before choosing Keep My Version, duplicate the file in Finder if you also want to preserve the other app’s version. Then Keep My Version can write your open content to the original file, with the disk version kept separately. When a recovery status offers Save a Copy, use that to preserve the content currently open.

Give the copy a clear name, then compare the versions and bring across the changes you want. For the next handoff, let the other app finish its editing pass before continuing your own.

A busy or unavailable file may need a moment.

If a cloud provider or another app has the file busy, Zizeg can show Autosave Paused while it checks access. Your open edits remain in memory; choose Save a Copy if you need a separate saved version.

When access returns, Zizeg resumes autosave and briefly confirms recovery. If you close the document while paused, the choices include Save a Copy and Close, Close Without Saving, or Cancel. If the original is missing or disconnected, use Save As or Save a Copy from the recovery status.

For reading and correcting the result of an agent’s work, see reviewing AI-generated Markdown. Reading is free; editing requires a one-time unlock or an active subscription.
