Same source. Different rendering.

The same file.
A different-looking document.

The quick answer

Markdown apps can use different styles and support different extensions. Compare the source first: a new font is a display change, unsupported syntax is a feature difference, and changed text needs a source review.

Check which difference you have.

  • Different appearance. Fonts, spacing and reading width can vary without changing the file. A soft line break can also render differently.
  • Different feature support. Tables, raw HTML and other extensions may be handled differently. Zizeg currently doesn’t render math, Mermaid or footnotes.
  • Different saved text. Use Split to inspect the Markdown alongside Preview. If syntax itself changed after editing, check the source-preservation page.
