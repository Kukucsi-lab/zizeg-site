The quick answer

A split preview can mean editable source beside a read-only result. Zizeg goes further: Preview and Source are both editors. Use either alone, or keep them together in Split with changes kept in sync.

Choose the view for the next change.

  • Preview is editable. Click the word, heading or table cell you want to change. Formatting commands work in the rendered document.
  • Source keeps the syntax visible. Inspect Markdown markers, metadata and whitespace directly. Both views work with the same .md file.
  • Split keeps both in sight. Choose ⌘3 for Split, ⌘1 for Preview or ⌘2 for Source. Click active Split again to swap pane order.
