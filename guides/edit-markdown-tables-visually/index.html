The quick answer

Click a table cell in Zizeg’s editable Preview and change its text. Use Table Operations to add or remove rows and columns, while Source keeps the underlying Markdown within reach.

Change the table where you read it.

  • Start with a table. Choose Insert → Table from the toolbar to add a 3-by-3 table, then fill in the headers and cells.
  • Change the structure. With the cursor in a cell, open Table Operations to insert or delete rows and columns. Press Tab to move between cells.
  • Keep the Markdown available. Split shows the table beside its source. Table edits can tidy the affected block; use Source when exact spacing matters.
  • Align the columns. Choose left, center or right alignment in Table Operations. The separate alignment page shows the Markdown markers too.
