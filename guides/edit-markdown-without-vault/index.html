Your document. Your folder.

One Markdown file.
No workspace to set up.

The quick answer

Open an existing .md in Zizeg and edit it where it already lives. No import, vault or proprietary library is needed. Preview and Source work on the same file, with ordinary edits autosaved in place.

Keep the file with the work.

  • Open, then edit. Use File → Open… or double-click when Zizeg is your default app. Correct the text in Preview or Source—including notes exported from Apple Notes.
  • Make a separate version. Choose File → Save As… before experimenting. The copy gets its own name or location; the original stays available.
  • Work across documents. Use native Mac tabs or separate windows. Keep companion image assets with the Markdown when moving or sending it.
