From generated draft to useful document

The AI wrote a draft.
Make it yours.

The quick answer

Open the generated .md in Zizeg, read it in Preview, and correct the text, tables or checklist directly. Keep Source alongside it in Split, then save your working Markdown or export a reviewed reading copy.

Three checks before you use it.

  • Check the facts yourself. Confirm names, dates, numbers, links and sources. Zizeg makes the draft readable; it does not verify its claims.
  • Correct what you can see. Edit a sentence or table cell in Preview. Check Source if a table or code block looks wrong, and untick tasks marked done too early.
  • Keep the right version. Use Save As… first if you need the original draft. Let an agent finish writing before you edit; use the external-change choices if versions differ.
