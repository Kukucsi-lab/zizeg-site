What's built in

Everything you'd expect. A few things you wouldn't.

EDITING

Dual-pane editing, always in sync

Work in the rendered WYSIWYG view, the raw source, or switch freely between them — edits in one are reflected in the other automatically. Not a read-only preview bolted onto a text pane; both sides are the real editor.

EDITING

Full formatting toolbar

One toolbar, works in both panes. In source, a click inserts the actual markdown characters (**bold**, ## Heading) right at your cursor. In WYSIWYG, the same click formats live, like Word. And you don't need the toolbar for the basics — type ## for a Heading 2, - for a bullet, as you go.

SAFETY

Content safety by default

Your saved .md file is never touched or rewritten for safety — a plain text file can't do anything dangerous on its own. Sanitization happens only where it matters: when content is rendered, against an allowlist, not "best effort." Remote images stay blocked until you click to load them.

FILES

Your files stay real files

Edits save straight to the actual .md file on disk — no proprietary format, no database, no import/export step.

FILES

Images travel with the file

Drop in a local image and Zizeg copies it into a plain sibling folder next to your document. Rename or move the file from inside Zizeg and the folder follows automatically. Rename it from outside Zizeg and Zizeg picks up the mismatch next time you open the file, offering to reconcile it for you.

FILES

Choose how images are stored

Keep images in the sibling asset folder — best for git repos, a small diffable file. Or embed them as base64 directly inside the .md — best for single-file portability. Zizeg follows whichever a document already uses; Save As is where you convert between the two.

SYSTEM

Preferences that stick

Startup size, default view, tab behavior, theme — the expected baseline. What's not standard elsewhere: WYSIWYG and source panes have fully independent font settings. Visual preferences apply live to documents already open.

SYSTEM

Built for macOS

Native window tabbing, a table of contents pane, row numbers, and full light/dark theming.

EXPORT

Export to HTML or PDF

Self-contained exports with local images inlined. If the document references remote images, you get a picker listing every one of them — pre-checked based on what you've approved — so you can include, exclude, or revoke any before export.
