Markdown, ready to send

From Markdown
to a readable PDF.

Keep your editable .md file, and send a paginated document your recipient can open without a Markdown app.

The quick answer

Open your file in Zizeg, then choose File → Export → Export to PDF…. Pick the page size and destination, choose any remote images to include, and check the saved PDF before sending. Reading is free; PDF export requires a one-time unlock or an active subscription.

Check the document before you export.

Open your .md file in Zizeg. If it is your default Markdown app, double-clicking in Finder is enough. Choose Preview (⌘1) to read the formatted result, or Split (⌘3) if you want Source alongside it. With Preview or Split set as your default, the formatted view is already there. While Split is active, clicking Split again swaps the Preview and Source sides.

Try a short report with a heading, a list, and a small table like this. Check the wording and any images while it is still easy to edit.

Read for free. Unlock export when you need it.

Opening and reading Markdown are free. Editing and HTML or PDF export require a one-time purchase or an active subscription.

Make the PDF from the open document.

  1. Choose File → Export → Export to PDF…Zizeg exports the content currently open in the editor, including recent edits.
  2. Choose a name, destination, and page size.The save panel offers A4, US Letter, US Legal, A5, A3, and Tabloid. Choose the paper your recipient expects.
  3. Decide whether to include front matter.If the file has metadata at the top, Include front matter appears in the save panel. Leave it unchecked for a reader-facing report unless the metadata belongs in the output.
  4. Choose any remote images to include.If the document references web images, approve the ones you want embedded. Finish the export, then open the saved PDF and check it.

The original Markdown stays a Markdown file. Export creates the presentation copy; it does not replace your source with a PDF.

Let the page size do the layout work.

The PDF reflows text to the selected paper size, with one-inch margins. Making the Zizeg window wider is not the way to change the exported page width. Export uses the Preview font family and size from Preferences → Editor.

Long code lines and links wrap. A table that is too wide is scaled down to fit, so check that its text remains readable. If it becomes too small, simplify the table, shorten column labels, or choose a larger supported page size.

For table content and structure changes, see editing Markdown tables visually. Export handles presentation; it does not turn a wide table into a different information layout for you.

Include the content the recipient needs.

Make sure local pictures can be read before exporting. If they are already missing in Preview, use the broken-image guide to check paths and folder access.

The remote-image picker lets you select or deselect individual web images, or use Select All and Select None. Images already loaded in Preview start selected. Unapproved or failed remote images are represented by placeholders rather than left as live image URLs.

Front matter is excluded by default on each export. Including it affects the exported copy, not the metadata stored in your Markdown source.

Not sure what the opening metadata is for? See the YAML front matter guide for a worked example and how to edit it in Source.

Open the PDF as your recipient will.

  • Check the opening page, heading breaks, and final page.
  • Read the smallest table text and any long code blocks.
  • Make sure the important images are present.
  • Check that private metadata is not included unintentionally.

Under Preferences → Export, you can set a default PDF page size and choose to open completed exports automatically. You can still change page size for an individual export.

If the recipient needs to edit the original, send the Markdown with its assets instead. If they prefer browser reading without fixed pages, consider standalone HTML. The format-choice guide helps you decide.
