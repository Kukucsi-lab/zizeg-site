Home/Guides/Export Markdown as Standalone HTML on Mac

Browser reading. One file.

One document.
One HTML file to send.

The quick answer

Choose File → Export → Export to HTML… in Zizeg. Accessible local images and approved remote images are embedded in a browser-readable copy. Keep the Markdown as your working file and send the HTML for reading.

Package the document, not the whole project.

  • Bring the pictures along. Choose the remote images to embed. Fix missing local pictures before exporting; unavailable images cannot be reconstructed.
  • Keep links in mind. Ordinary links remain links. A reference to another document does not turn that document into an embedded attachment.
  • Check the copy you send. Open the saved HTML in a browser. Leave front matter excluded unless needed, and use PDF if the recipient cannot accept HTML attachments.
