Pictures where they belong

Add the screenshot.
Keep the context.

The quick answer

Paste an image, drag it into Zizeg, or choose Format → Image…. With the default Assets Folder storage, save a new document first. Zizeg stores the picture beside your Markdown and inserts its reference.

Three ways in. One plain file.

  • Use what you already have. Paste a screenshot with ⌘V, drop an image from Finder, or choose a picture from disk.
  • Let Zizeg handle the path. The default keeps pictures in a companion assets folder. Approve folder access if macOS asks.
  • Describe the useful detail. Add alt text that explains the picture. Check its position in Preview, then keep the image folder with the .md when sharing.
