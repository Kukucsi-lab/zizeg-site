From .md to a readable document

Someone sent a .md.
Open it and read.

The quick answer

Open a Markdown file in Zizeg with File → Open…, or double-click when it is your default .md app. Preview shows the formatted document; Split keeps the source alongside it. Reading is free.

Read the file you already have.

  • No import needed. Open the .md or .markdown where it lives. There is no vault or library to create first.
  • Choose your view. Use Preview for reading or Split for text and formatting together. Set the default for new tabs in Preferences → General.
  • Keep its pictures nearby. If the file came with an image folder, preserve that relationship. Missing pictures often need their assets, not a different reader.
