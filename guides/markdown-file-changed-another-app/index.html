Choose the version you mean to keep

Another app changed it.
Which version do you want?

The quick answer

Choose Reload to use the file another app wrote to disk. Choose Keep My Version to write the content currently open in Zizeg over that version. If both matter, duplicate the disk file before deciding.

Two versions. One clear choice.

  • Reload the new result. Use this when an agent or another editor has finished updating the file. Reload is one undo step in Zizeg.
  • Keep your open version. Keep My Version writes it immediately to the original file. Zizeg checks the disk revision before applying the choice.
  • Keep a copy when needed. Duplicate the disk file before overwriting it. If autosave is paused or the original is unavailable, use Save a Copy from recovery status.
