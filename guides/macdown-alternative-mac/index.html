The quick answer

Open an existing .md file in Zizeg and choose Split to keep Source and Preview together. Your files stay in their folders. Try a representative document, its images, and your usual edits before changing your default app.

Your documents can stay where they are.

If you use MacDown with ordinary .md files, trying Zizeg starts with opening one of those files. There is no library to import or vault to create. Choose File → Open… in Zizeg, or use Finder’s Open With menu.

Pick a document you know well, with a few headings, links, and images. Keep its companion assets in place. This makes it easy to compare the experience before changing your default app.

Use Split, then try editing in Preview.

Choose Split (⌘3) to see Source and Preview together. You can also use Source alone (⌘2) or Preview alone (⌘1), and set your preferred default viewing mode.

MacDown shows a live preview beside your source. In Zizeg, you can edit in both: correct text, change a table cell, or tick a task directly in the formatted document. Typing, shortcuts, toolbar controls, and app menus work in either editor; both views stay in sync.

For a closer look at the different models, see source, read-only preview, and editable Preview.

Start by reading your own files for free.

Editing and HTML or PDF export are available through a Lifetime Unlock or an active subscription.

Try your usual document before switching.

  • Read the headings, lists, and tables in Preview.
  • Check that images appear and links lead where you expect.
  • Try a small edit on a copy made with File → Save As… (⇧⌘S).
  • If you export documents, open a sample PDF or HTML export.

Zizeg currently doesn’t render math, footnotes or Mermaid diagrams. Math and Mermaid support is coming in the next version, 1.2.0. Until then, if your MacDown notes use math, try one of those first. If another feature looks different, use the cross-app Markdown guide to check the cause. If a picture is missing, check its path and folder access.

Change the default when you are ready.

If Zizeg suits your files, set it as your default Markdown app. After that, double-clicking a .md in Finder opens it in Zizeg. Follow the default-app guide for the steps.

This guide refers to the original MacDown project. If you use a fork, check that project’s features separately. For a broader workflow comparison, see the editor comparison.
