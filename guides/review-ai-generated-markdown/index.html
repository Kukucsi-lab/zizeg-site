From generated draft to usable document

The AI wrote a draft.
Make it yours.

Read an AI-generated draft comfortably, make your changes, and keep a version you can use.

The quick answer

Open the generated .md in Zizeg, read it in Preview, and correct the text, tables, or checklist directly. Use Split when you want Source alongside the document. Keep the Markdown for further work, or export a reviewed PDF or HTML copy to share.

Open the draft and read it comfortably.

If an AI assistant gives you a plan, specification, or report as a .md file, open it in Zizeg. Headings, lists, and tables appear as a formatted document, making it easier to read through the draft.

If Zizeg is your default Markdown app, just double-click the file in Finder. Choose Preview (⌘1) for reading or Split (⌘3) to see Source alongside it. With either set as your default viewing mode, the formatted view opens automatically.

Click the active Split control again to swap the panes.

Read through it before making changes.

Check whether the draft says what you intended. Look for missing details, unclear wording, and names or dates that need correcting.

For example, a plan might say “Send the draft on Friday” when you agreed on Monday. You can correct that sentence directly in Zizeg as you read.

Want a file to try? Download a short example plan.

Make corrections directly in the document.

Click into Preview to change a sentence, update a table cell, or tick a task. You can also use shortcuts, toolbar controls, and app menus in either editor. Preview and Source stay in sync.

For the specific steps, see editing tables or working with checklists.

Reading is free.

Editing and HTML or PDF export are available through a one-time unlock or an active subscription.

Keep your changes in the Markdown file.

Zizeg autosaves ordinary edits to the open file. To keep the original AI draft as well, choose File → Save As… (⇧⌘S) before editing and work on a separate copy.

If an agent or another app is still writing to the same file, let it finish before you start editing. If Zizeg reports an external change, Reload opens the version on disk; Keep My Version writes the version currently open in Zizeg.

For the full explanation, see Reload, Keep My Version, and saving a copy.

Send the version your reader needs.

Send the .md and any image assets when someone needs to keep editing. For a finished reading copy, export PDF or standalone HTML, then open the exported file to check it before sending.

See Markdown, PDF or HTML? if you are unsure which format to use.
