Blocked and broken are different

An online image.
A missing picture.

The quick answer

If Zizeg shows “Remote image blocked”, check the domain and click to load when you want the image. If it still fails, check the URL and server access. A loading setting cannot fix an unavailable picture.

Check the cause before the setting.

  • Recognize the default. Block and click to load is the default under Preferences → Safety → Remote content. Loading contacts the image’s server.
  • Check the actual address. The destination must return an image, not a web page or sign-in screen. A picture visible in your browser may still need private access.
  • Check the shared copy too. The export picker controls which remote pictures are embedded. Preview approvals are session-based; open the exported file before sending it.
