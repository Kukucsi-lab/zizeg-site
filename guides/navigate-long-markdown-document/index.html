The quick answer

Use Zizeg’s Table of Contents to jump between headings, and Find (⌘F) for a word or phrase. Split and Source row numbers keep the Markdown available when you need a precise reference.

Use the map, then the text.

  • Jump by heading. Click Table of Contents in the toolbar. The outline follows your heading levels and highlights the section as you scroll.
  • Find the wording. Press ⌘F, enter the phrase, then Return for the next match. Source search can include Markdown characters.
  • Keep a source reference. Turn on Row Numbers beside Table of Contents. In Split, click the active Split control again if you prefer the opposite pane order.
