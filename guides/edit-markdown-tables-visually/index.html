Tables without the syntax juggling

Change the table.
Keep the Markdown.

Edit cells, rows, and columns as part of the document you’re reading—without counting separators in the source.

The quick answer

With editing unlocked in Zizeg, click a table cell in Preview and edit its text directly. Use Table Operations to add or remove rows and columns or set column alignment. The table stays Markdown, and you can inspect its source in Split view.

Start with the information, not the pipes.

A Markdown pipe table has a header row, a separator row, and data rows. The vertical bars separate cells. You can write all of that by hand, or use a visual editor to handle the structure while you work on the contents.

The saved Markdown

| Task   | Owner | Status |
| :----- | :---- | :----- |
| Draft  | Anna  | Ready  |
| Review | Ben   | Next   |

The rendered table

TaskOwnerStatus
DraftAnnaReady
ReviewBenNext

Use a small table like this to try the workflow. The goal is the same ordinary Markdown; you’re choosing a more convenient way to edit it.

Insert a table in Zizeg.

  1. Open your document in Preview or Split.Choose View → Preview (⌘1) or Split (⌘3). With editing unlocked, put the cursor where the table should go.
  2. Choose Insert → Table from the toolbar.Zizeg inserts a 3-by-3 table. Use the header cells for Task, Owner, and Status.
  3. Enter your rows.Fill in Draft / Anna / Ready and Review / Ben / Next. Press Tab to move to the next cell.
Read for free. Unlock editing when you need it.

Opening and reading are free in every view. Editing and HTML or PDF export require a one-time purchase or an active subscription.

Change the structure where you’re working.

Place the cursor in a table cell, then open Table Operations from the toolbar’s Insert menu or the cell’s contextual menu.

  • Add a row: insert above or below the current row. For example, add a Publish task below Review.
  • Add a column: insert before or after the current column. Add Due after Status when the table needs dates.
  • Remove what you no longer need: delete the current row, column, or the whole table.

These actions let you change the table without manually adding a separator to every source line. Deleting the final row or column removes the table itself.

Align one column at a time.

Click a cell in the column you want to change, then use Table Operations to choose left, center, right, or default alignment.

Left alignment works well for descriptive text. Right alignment can make a column of short numbers easier to scan. Alignment is stored in the Markdown separator row, using colons such as :---, :---:, or ---:.

That changes the alignment within cells. It doesn’t turn the document into a spreadsheet or add calculations.

Keep the source available.

Choose Split to see your rendered table beside its Markdown. Edit a cell in Preview and watch Source update, or change its text in Source and see the rendered result.

Zizeg normally keeps Preview changes localized, but a table edit may reformat the affected block. Use Source when precise spacing or a particular syntax choice matters. You don’t have to keep every pipe visually lined up in the text just to read the rendered table.

Some apps support different table dialects. This guide uses the common GitHub Flavored Markdown pipe-table form, not grid tables, merged cells, or spreadsheet formulas.

See how editable Preview differs from a read-only split preview for the broader editing model.

A quick exercise for your next document.

Take the sample table above, change Ben to another owner, add a Publish row, then add a Due column. Align the column that benefits from it and check the result in Source.

You’ve edited the content, structure, and presentation without changing the file format. To send a finished table as part of a readable report, see exporting Markdown to PDF. Zizeg autosaves ordinary edits in place. If you want to experiment without changing the original document, use File → Save As… first.
