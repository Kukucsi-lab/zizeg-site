One file, two editable views

Edit in the rendered view or raw Markdown. Both views work on the same document and stay in sync automatically — there is never a separate visual copy to reconcile.

✓

Real files, no vault

Zizeg works directly with plain .md files on disk. No proprietary database, no import step, and no lock-in — open the same file in another editor, commit it to Git, or hand it to another tool.

✓

Safety without rewriting

Safety checks never rewrite the saved source behind your back. Zizeg sanitizes only when rendering or exporting, blocks remote images until you approve them, and visibly flags unsafe or unsupported content.

Built for AI-assisted work

Markdown you can hand-edit — and hand back to your AI agent.

AI tools constantly produce READMEs, instruction files, specifications, plans, changelogs, and summaries. Zizeg gives you a comfortable place to review, format, and correct them — visually or in raw source — while keeping every document as plain, portable Markdown.

Zizeg itself does not use AI or send your documents to an AI service. It simply makes the Markdown around AI-assisted work easier to maintain.

Beyond the basics

EDITING

Formatting in either view

Use the same formatting toolbar in either view. In Source, commands insert real Markdown at the cursor; in Rendered, they format the document live. Switch views without changing tools or reconciling separate copies.

IMAGES

Images that travel with the file

Drop or paste an image and Zizeg stores it in a normal sibling assets folder. Rename or move the document inside Zizeg and the folder follows. Rename it in Finder and Zizeg offers to repair the resulting mismatch.

IMAGES

Folder or single-file images

Keep images as ordinary files for clean Git diffs, or embed them as base64 for single-file portability. Zizeg respects whichever approach a document already uses, and Save As can convert between them.

EXPORT

Export with control

Export self-contained HTML or multi-page PDF using the same rendering you see on screen. Local images are included automatically; for remote images, you choose exactly which ones may be fetched and embedded.

NAVIGATION

Navigate larger documents

Move through longer files with a table of contents, source row numbers, and Find tailored to the active view. In Split view, keep scrolling synchronized or let each pane move independently.

MACOS

Made for macOS

Native window tabs, light and dark themes, default .md file handling, and detailed preferences for startup and view layout. Choose the font family and size independently for the rendered and source panes, and decide whether the panes scroll together in Split view — the document content stays synchronized either way.
