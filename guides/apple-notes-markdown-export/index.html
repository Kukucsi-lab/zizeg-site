From a note to a plain file

Take the note with you.
Keep working in Markdown.

Open an exported Apple Note, make your changes, and keep it as a file in the folder you choose.

The quick answer

In Notes on macOS Tahoe 26, choose File → Export as → Markdown. Open the exported .md in Zizeg to read and edit it, and keep any accompanying assets with the file.

Start with one note.

In Apple Notes on macOS Tahoe 26, select the note, choose File → Export as → Markdown, then choose a name and destination and click Save. This gives you a Markdown copy to use outside Notes.

These menu steps follow Apple’s Notes guide for macOS 26. If your Notes version does not offer Markdown export, check the guide for your macOS version.

Read it as an ordinary Markdown document.

Find the exported .md in Finder and open it in Zizeg. If Zizeg is your default Markdown app, double-clicking is enough.

Use Preview (⌘1) for the formatted note, or Split (⌘3) to see its Markdown as well. With Preview or Split set as your default viewing mode, the formatted view opens automatically.

Take a quick look at what came across.

For a meeting note with headings and a screenshot, check that the headings are readable, the list items are in order, and the picture appears. In Source, an image reference shows where that picture is stored.

The folder and filename above are examples. Use the actual path in your exported document. If Notes created accompanying image or attachment files, keep them with the Markdown in their existing folder structure.

If a local picture is missing, see checking image paths and folder access. You can also add or replace an image in Zizeg.

Edit the note where it now lives.

Correct a sentence, update a heading, or add your next steps directly in Preview. Shortcuts, toolbar controls, and app menus work in both Preview and Source, and the two views stay in sync.

Zizeg autosaves ordinary edits to the Markdown file. Use File → Save As… (⇧⌘S) first if you want to keep an untouched export alongside your working copy.

Read the exported note for free.

Editing and HTML or PDF export are available through a Lifetime Unlock or an active subscription.

Choose where you want to continue.

Keep working with the Markdown, or send a readable copy using PDF or standalone HTML.

To bring a Markdown file into Notes on a supported version, choose File → Import Markdown, select the file, and import it. Apple describes the process in its Markdown import instructions.

Export and import create copies; edits to the .md do not automatically update the original note. Check formatting and attachments after a transfer, especially if you plan to move the document back and forth.
