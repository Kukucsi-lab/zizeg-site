Small edits. Less cleanup.

Edit Markdown.
Keep your formatting.

The quick answer

Edit directly in Zizeg’s Preview while keeping Source alongside it. Your surrounding Markdown usually stays as written. Simply reading a file doesn’t rewrite it; use Source when exact syntax matters.

Keep a small change small.

  • Fix the wording in Preview. Make the correction where you read, then check Source in Split.
  • Your content stays the same. If Zizeg tidies the source, it only standardizes the Markdown syntax to GitHub Flavored Markdown (GFM).
  • Control the details in Source. Edit list markers, indentation and whitespace directly when they matter.
