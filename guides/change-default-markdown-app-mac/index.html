Make double-click work for you

Markdown opens in the wrong app?
Change the default.

Double-click a .md file and get Xcode, TextEdit, or another editor? Choose the app you actually want to read it in.

The quick answer

In Finder, select a .md file, open Get Info (⌘I), choose your app under Open with, then click Change All…. To choose Zizeg directly, use Zizeg → Preferences… → General → Set as Default App for .md Files.

Need to open it just this once?

Control-click the .md file in Finder, choose Open With, and select Zizeg. You can also open Zizeg first and choose File → Open….

This is useful when you want to try another reader without changing your usual setup. To make double-clicking use the same app next time, change the default for the file type.

Make your choice stick in Finder.

Finder can set your preferred app for files of the same type. Start with an ordinary .md file.

  1. Select the file and open Get Info.Choose File → Get Info, or press ⌘I.
  2. Find Open with.Expand the Open with section and select the app you want to use.
  3. Apply it to the file type.Click Change All… and confirm if prompted. This applies the choice to matching files, rather than only the selected document.
  4. Try double-clicking a Markdown file.It should now open in the app you chose.
One file or every file?

Leave out Change All if you only want to change the selected file’s association. Use Change All when you want this to be your normal app for that file type.

Or set Zizeg as the default from the app.

In Zizeg, choose Zizeg → Preferences… → General, then click Set as Default App for .md Files. After that, double-click a .md file in Finder to open it in Zizeg.

You don’t need to import the document or move it into a library. Zizeg opens the ordinary Markdown file where it already lives.

New to the format? Our guide to opening and reading Markdown shows what you’ll see in Preview and Source.

The app and the view are two separate choices.

Your Mac decides which app opens the file. Zizeg’s default view decides how a newly opened document appears.

Under Preferences → General → Default view for new tabs, choose Preview for the formatted document, Split for formatting and source together, or Source for raw Markdown.

With Preview or Split selected, the formatted view appears when you open a new document—there’s no need to choose it each time.

Reading is free in every view.

Editing and HTML or PDF export require a Lifetime Unlock or an active subscription.

Still opening somewhere else?

  • Check the extension. A .markdown file may have a different association from a .md file. Repeat the Finder steps for the type you actually use.
  • Check the scope. Choosing an app for one file is different from using Change All.
  • Check the app is installed. If you don’t see Zizeg in the choices, open it from Applications first.
  • Try opening from inside the app. If File → Open… works, you can read the document while sorting out the Finder association.

You can switch back to another default app using the same Finder steps. Changing the association does not convert the file or change its contents.
