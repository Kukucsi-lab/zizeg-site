Keep visual writing. Try a Mac workflow.

Like visual Markdown?
Keep Source beside it.

The quick answer

If you want editable Preview and Source side by side in a native Mac document workflow, try Zizeg with an existing file. Test your usual edits and syntax before changing your default app.

Compare the workflow you actually use.

  • Edit in either pane. Typora offers Live Preview and Source Code Mode. Zizeg’s Split keeps editable source and formatted text visible together.
  • Use familiar Mac controls. Work with native tabs, windows, menus and autosave. The heading outline and Source row numbers help you find your place.
  • Check specialized syntax. Zizeg currently doesn’t render math, Mermaid or footnotes. Math and Mermaid are planned for the next version, 1.2.0.
  • Choose your access model. Zizeg offers a Lifetime Unlock or subscriptions. Typora also sells a one-time license, so compare features and workflow as well as purchase preference.
