Someone sent a .md.
Start by reading it.

Understand the links and images in a Markdown file, with control over the online content you load.

The quick answer

Usually, yes. A Markdown file is plain text, and Zizeg doesn’t run scripts in it. By default, online images stay blocked until you allow them, and Zizeg asks before following a local link to an app or script. Check links before you click, as you would in an email.

Open the document without uploading it to a converter.

You can read a Markdown file in a local app such as Zizeg without sending the whole file to an online conversion service. If Zizeg is your default Markdown app, double-click the file in Finder, or choose File → Open….

The document can still contain references to online content. Online images are blocked by default. You can change this under Preferences → Safety → Remote content.

An image and a link behave differently.

[Project website](https://example.com/)

The image asks the viewer to display a resource from a server. With click-to-load enabled in Zizeg, it starts as a placeholder until you approve it. Loading it contacts that server and can reveal that the document was opened.

The ordinary website link is followed when you click it; Zizeg does not download its target just to render the text. Check the destination before following an unfamiliar link.

The example addresses above show the syntax; they are not required resources for this guide. For a picture that fails to load, see remote-image troubleshooting.

Zizeg applies safety rules when it displays the document.

Preview and exports remove or neutralize unsafe content such as scripts and event handlers. Some raw HTML is also omitted because the editor does not support it. The source remains available to inspect.

Under Preferences → Safety, you can enable Highlight sanitized and unsupported content. Amber marks content removed for safety; red marks unsupported content. These indicators help explain a rendering difference and are not included in exports.

These controls help you choose what to load and follow. They do not verify that a document’s claims or linked destinations are trustworthy.

Keep the choices with you.

Use click-to-load for unfamiliar remote images, and open links when you want to visit their destinations. Local viewing avoids uploading the whole document, while your remote-content settings determine whether its online images are requested.

When exporting to HTML or PDF, choose which remote images to include in the export picker. Open the finished copy before sharing it.

Reading is free. Editing and export require a Lifetime Unlock or an active subscription.
